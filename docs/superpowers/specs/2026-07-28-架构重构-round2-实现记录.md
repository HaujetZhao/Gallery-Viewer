## R2+R3 扫描优化 ✅(已实现,用户验收通过)

- 设计:[spec](./2026-07-28-round2-R2R3-扫描优化-design.md) · [plan](../plans/2026-07-28-round2-R2R3-扫描优化.md)
- **改动**:把「每次打开全树后台扫 + 全量持久化 + 全树计数」拆成「显示走快照、校验走按需、持久化走 dirty」。
  - [stores/fs.js](../../src/stores/fs.js):加 `rootDirty` ref。
  - [services/filesystem.js](../../src/services/filesystem.js):
    - `integrateScanResult`:检测增删(newFiles/removedFiles/newSubFolders/removedFolders)→ 置 `rootDirty`。
    - `persistIfDirty(id)`:仅 dirty 时 `saveScan` + `getAllFiles`(砍 W2/W3:未变零序列化/零计数)。
    - `rootEagerScan(root)`:只扫 root 一层 `scanFolder(trust)`(砍 W1:不递归全树)。
    - `switchToRoot` 有 snap → `rootEagerScan` + `persistIfDirty`(无 snap/失败 → 全树扫建快照,首次不变)。
    - `handleFolderClick` → 对所有点击 `scanFolder(trust)` + enrich + `persistIfDirty`(深层按需;替代原 `<200 refreshFolder`)。
    - `scanAndPersist`(首次/reload)末尾用 `persistIfDirty`(全树扫后必 dirty)。
  - [stores/history.js](../../src/stores/history.js):`executeOperation`/`undoLastOperation` 后置 `rootDirty`(rename/delete/move 持久化;model 层不动)。
  - +6 单测(`integrateScanResult dirty` ×3 + `persistIfDirty` ×3,mock scanCache/handleStore 避免 IDB 副作用)。
- **commits**:`8905db3`·`6c05592`·`600b5c6`·`fcd439e`·`e833763`·`d80d7b8`
- **理想终态**:重复打开无变更 = 0 全树 readdir / 0 getFile / 0 IDB 写 / 0 全树计数。
- **验收**:用户用临时 `[scan]` console.log 验证——重复打开大树无变更时 `persistIfDirty skip`(零 IDB 写)、顶层新增 `SAVED`、深层点开刷新、rename/delete 后重开持久化。✅ 通过(log 已删,代码干净)。

## R5 批量写 _meta ✅(已实现,待用户验收)

- 设计:[spec](./2026-07-28-round2-R5-批量写meta-design.md) · [plan](../plans/2026-07-28-round2-R5-批量写meta.md)
- **改动**:[SmartFolder.enrich](../../src/models/SmartFolder.js) 拆「并发 getFile」+「同步批量写 _meta」:
  - worker 只 `getFile + acquire`(池缓存 size/mtime,不响应式)返回 `{f, size, lastModified}`;**不再逐个写 _meta**。
  - `runConcurrent` 收齐后,一个**同步 for 循环**批量写 `_meta`;Vue 把同步块内多次响应式变更批成**一次 flush** → sort computed 只重排一次。
  - 修 size/date 排序 `O(N²)` sort 风暴(enrich 期间重排 N → 1)。name 排序不受影响。cancel 语义保留(worker 查 token + 收齐后查)。

- **验收**:lint/test 过(行为不变,现有 enrich 测试仍过);**待用户主观验**(size/date 排序大文件夹 enrich 期间不再跳序/卡顿)。
