# 多设备响应式优化 design

> 日期：2026-08-05 ｜ 分支：`feat/responsive-multidevice`
> 现状：本质"桌面固定布局"，`@media` 仅 6 处零散折衷。目标：移植「英语学习」项目的断点驱动侧栏模型，补齐移动端 viewport/safe-area/触屏交互与图库列数自适应。

## 背景

`d:\repos\相册浏览器-pwa` 是纯本地处理的相册浏览器（File System Access API，仅 Chromium）。当前多设备现状：

- 侧栏 `Sidebar.vue:68-82` 是 `fixed + translateX(-100%) + hover 滑出`，**触屏无 hover 即无法唤出**；窄屏只有 `margin-left:0` + 300px 覆盖层，无汉堡/抽屉/backdrop。
- 左上 `.settings-btn`（50px 圆钮）+ 顶右筛选框（250px + `padding-right:108px`）固定像素，小屏互相遮挡、越出视口。
- 用 `100vh`/`innerHeight`（无 `dvh`）、零 `env(safe-area-inset)`。
- `--col-count` 硬取用户设置（默认 4），容器变窄列不变 → 卡片越来越小。
- 无断点状态基础设施：matchMedia 全是瞬时的、散落的。
- 触屏 hit-target 仅 `PhotoCard` 一处 `touch-action:none`。

「英语学习」项目（`C:\Users\Haujet\Desktop\英语学习`）的**迟滞双阈值断点 + pinned/overlay 双态 + FAB 唤出 + scrim 遮罩**正是为"桌面浏览器 ↔ 触屏窄屏"这种跨度设计的，直接移植。

## 目标范围

1. **侧栏响应式**（移植英语学习模型）。
2. **设置触发入口迁移**：左上 FAB 改为侧栏唤出；设置入口移至侧栏底部齿轮。
3. **图库列数自适应**。
4. **A. `dvh` + safe-area 适配**。
5. **B. 触屏 hit-target + 触屏 hover 映射**。

## 设计

### 1. 侧栏响应式（迟滞双阈值 + pinned/overlay）

参考 [英语学习 App.vue](C:/Users/Haujet/Desktop/英语学习/src/App.vue) 的 `BP` 迟滞双阈值状态机。

**断点（监听 `innerWidth`，rAF 节流）**：

| 视口 | 侧栏行为 |
|------|---------|
| `> 900px` | 可 **pin 常驻**（推挤图库，目录树一直在） |
| `< 880px` | 自动切 **overlay 抽屉**（盖在图库上） |
| 900–880 | 20px 缓冲带，迟滞防边界抖动 |

**状态机**（仿英语学习 `recompute`，模块级或 store 级）：

```
width > BP.pin   → pin = true
width < BP.unpin → pin = false
// 跨阈值清手动标志，让自动态重新接管
```

**pinned（推挤）/ overlay（浮层盖内容）双模式**：
- pin：`.layout.left-pinned` 下中栏 `padding-left: var(--sidebar-width)`（英语学习 `.layout.left-pinned .panel-center { padding-left }`），单一通道。
- overlay：侧栏悬浮 + `scrim` 遮罩（`.layout.left-overlay .scrim.show`），点遮罩关闭。
- **窄屏抽屉**滑出时 `max-width: 86vw` 钳制防越出窄屏（`--sidebar-width` 由拖宽上限 `innerWidth*0.8` 决定，再加 86vw 兜底）。

**FAB**（左上）：
- 侧栏收起态淡入（`opacity:1`）、pin 常驻时隐藏、overlay 展开时淡出让位。
- 点击：宽屏 toggle hide（收起↔展开）；窄屏 toggle overlay。
- 与英语学习 `[` 快捷键一致（若 PWA 无此快捷键可省略，保留既有快捷键体系）。

**pin 偏移单通道重构**：
现状 `App.vue` 用 JS `mainStyle`（`marginLeft`）+ `body.sidebar-pinned` CSS 复算两条通道维护同一偏移。重构为 **CSS 变量 + 单一 `.layout` class** 驱动，消除双通道隐患。`.main-content-wrapper` 的偏移由 `.layout.left-pinned` 下的 `padding-left: var(--sidebar-width)` 或等价的单一来源决定。

### 2. 设置触发入口迁移

- 左上 FAB 从"打开设置"改为"唤出/收起侧栏"。
- **齿轮按钮放侧栏底部**，点击弹出现有 `SettingsPanel` 浮层（表单代码不动，只换触发位置）。
- 清理散落在内容上的 `.settings-btn` 固定定位（移除/迁移）。

### 3. 图库列数自适应

`--col-count` 从"硬取用户设置"改为：

```
实际列数 = min(用户设置的 columnCount, 视口允许列数)
```

**视口允许列数**（`innerWidth` 断点，rAF 节流响应）：

| 视口宽度 | 视口允许列数 |
|---------|------------|
| `< 480px` | 2 |
| `480 – 768px` | 3 |
| `768 – 1100px` | 4 |
| `≥ 1100px` | 用户偏好（1–10，默认 4，不封顶） |

用户 `columnCount` 范围 1–10，默认 4（`src/config/index.js:34`、`SettingsPanel.vue:321`）。`colCount` 设置语义从"硬列数"变为"桌面目标列数上限"。

### 4. A. `dvh` + safe-area 适配

- 侧栏/主内容 `100vh` → `100dvh`（带 `100vh` 回退或直接 dvh，视支持度）。
- 大图/媒体用 `innerHeight`/`vh`（`useModal.js:68`、`MediaView.vue:271`）→ 补 `dvh` 兜底。
- 全局加 `env(safe-area-inset-*)` 适配：固定定位浮层（FAB、toast、modal 关闭按钮、底部栏）在刘海屏/全屏 PWA 下不贴边。
- 移动端地址栏收起/展开高度跳变，由 `dvh` 解决。

### 5. B. 触屏 hit-target + 触屏 hover 映射

**hit-target**：窄屏下给主要点按热区（筛选按钮、卡片操作、侧栏收起）加大热区，符合触屏最小 44px 目标。

**触屏 hover 映射**（`@media (hover: none)` 区分桌面/触屏，桌面 `:hover` 逻辑不动）：

| hover 行为 | 触屏拖动时 | 说明 |
|-----------|-----------|------|
| 视频/动图预览 | ✅ 做 | 拖动时循环播放，松手停止 |
| 备注 overlay | ✅ 做 | 无副作用 |
| 媒体展开变形 | ❌ 不做 | 避免滚动抖动 |
| 收藏爱心显现 | ✅ 展示但**不可同手势点** | 松手后再点才收藏 |

**实现要点**：`PhotoCard` 现用 `@mouseenter/@mouseleave`（`PhotoCard.vue:359-360`）驱动 `cardHovered`/`hoveredFile`。触屏设备改为"按下卡片 + 上下拖动 = hover"（`pointerdown` + 位移阈值区分"拖动滚动"vs"点按"）。触屏拖动起的是**展示态**，收藏爱心等操作按钮不能在同一手势里触发，松手后再点。

## 非目标 / 不做

- 不做触屏专属的完整重排（图库仍为网格，不做瀑布流/单列切换）。
- 不改 `persistence.js`、核心 scan/排序/缩略图算法（CLAUDE.md 核心算法稳定约定）。
- 不引入断点之外的容器查询重构（`Gallery` 的 ResizeObserver 自适应保留）。
