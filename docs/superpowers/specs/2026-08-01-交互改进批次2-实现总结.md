## 各任务实现要点

### R1 · 根列表拖拽排序 → 安卓式实时挤位

**数据层**:
- [handleStore.js](src/services/handleStore.js) 加 `reorder(ids)`:按序重排内存 cache + persist。
- [stores/root.js](src/stores/root.js) 加 `reorder(ids)`:重排响应式 `roots` + 同步 handleStore(与 `updateMeta` 同款"两边同步")。

**交互层** [RootSwitcher.vue](src/components/RootSwitcher.vue):
- 原生 HTML5 drag + `<TransitionGroup>` 实时挤位(用户在分叉中选的"幽灵跟随 + 实时挤位"方案)。
- `dragstart` 拷贝 `rootStore.roots` 的 id 序列到 `localOrder`;`dragover` 实时按指针 y 算落点 → 重排 `localOrder` → TransitionGroup FLIP 滑动让位;`drop` 提交 `rootStore.reorder(localOrder)`;`dragend` 清理。
- 被拖项半透明(opacity .4),浏览器原生幽灵跟随手指。
- `.root-add`(打开新文件夹)固定在 TransitionGroup 外,不参与拖拽。

**关键算法修复**(任务书原方案有 bug):
- 任务书的 before/after 半区算法,在"移除被拖项后用 `indexOf(target)` 算插点",导致**拖到相邻项下半 = 落回原位 = 视觉无响应**(用户实测:"拖第4到第3要拖两次才生效")。
- 改为:落点按"**非被拖项**中心"算 `insertIndex`(指针在某项上半→插它前),`localOrder.filter(id !== dragId)` 后回插。彻底消除原位 bug。

**光标闪烁修复**(用户反馈,三轮调试):
- 现象:开始拖、经过条目边缘、FLIP 元素掠过鼠标时,鼠标闪"禁止放置"光标。
- 根因:HTML5 drag 进入新元素**先触发 `dragenter`**,其默认行为是禁用光标;**只有 `dragover` preventDefault 不够**。
- 修法:`dragstart` 期间在 document 上对 `dragover` **和** `dragenter` 都 preventDefault + `dropEffect=move`(只在 `dragId` 存在期间挂载,`dragend`/`onBeforeUnmount` 卸载)。

### R2 · 切根后台递归整树校验

- [folderActions.js](src/services/folderActions.js) `switchToRoot` 快照分支:从"只扫 root 一层(`rootEagerScan`)"改为复用 `scanAndPersist`(全树 `startBackgroundScan` trust 校验 + `persistIfDirty`)。
- 删除 `rootEagerScan` 函数与死变量 `restoredFromSnap`。
- 效果:切根秒显快照后,后台递归整树做名字集合校验(trust 一致零 IO),深层磁盘增删**不再依赖点开才拾取**。

### R3 · modal 打开检测文件"改"(清 md5)

- [SmartFile.js](src/models/SmartFile.js) 加模块级**纯函数** `detectFileChange(file)`:复用 `peek` 的 File(省一次 getFile,因 modal 已 `ensureBlobUrl`),比 `_meta`,变则更新 `_meta` + `md5=null`。不碰 store。
- [MediaModal.vue](src/components/MediaModal.vue) `watch(currentFile)` 打开时调;**关 modal 时若变了**调 `triggerRedraw()` 重挂卡片 → `useThumbnail` 按新 md5 重生缩略图。
- 设计点:`useThumbnail` 的 `loaded` ref 不会因 `md5` 变 null 自动重算,必须重挂卡片;`triggerRedraw`(已有,`forceRegenerateCurrentThumbnails` 同款信号)是最小成本的精准重挂当前视图。

### R4 · 根目录右键菜单(删除禁用)

- [ContextMenu.vue](src/components/ContextMenu.vue) 补 `.context-menu-item.disabled` 灰显 CSS(`opacity:.4` + `pointer-events:none`)。模板对 `disabled` 字段的支持早就有,只缺样式。
- [SidebarTreeItem.vue](src/components/SidebarTreeItem.vue) `onContextmenu` 去掉 `isRoot` 早 return;根目录也 `preventDefault` + 弹**同款菜单**,但给"删除文件夹"项传 `disabled: props.isRoot`。

### R6 · 收藏(md5)+ 卡片爱心 + L 键

- 新建 [stores/favorites.js](src/stores/favorites.js):`Set<md5>` 内存镜像 + idb-keyval 持久化(key `favorites`)。`load()` / `isFavorite(md5)` / `toggle(md5)`。响应式靠 `toggle` 内整体替换 Set(`.has` 不被 Vue 追踪,故 replace)。
- 新建 [composables/useHoveredFile.js](src/composables/useHoveredFile.js):模块级单例 `ref`,PhotoCard `mouseenter`/`mouseleave` 写它。避免 Gallery→PhotoCard 穿 props 透传。
- [PhotoCard.vue](src/components/PhotoCard.vue) 左上角爱心:已收藏常显实心红、未收藏 hover 显空心,`md5` 未算(GIF/SVG/未进视窗)不显示爱心;`@click.stop` 防冒泡开 modal。
- [App.vue](src/App.vue) `onKeydown` 加 `L` 键;`onMounted` 调 `favorites.load()`(不阻塞、无句柄依赖)。

**偏离任务书(已记录)**:任务书 R6 指定 L 键加在 `useModal.onKeydown`;**实际统一放 `App.vue.onKeydown`**。理由:
- `App.vue` 已有全局 `onKeydown`(Ctrl+O/Z)且已做 INPUT/TEXTAREA 守卫,一处统一避免与 `useModal` 的 window keydown 监听并存/抢键。
- modal 打开优先切 `modal.currentFile.md5`,否则切 `hoveredFile.md5`;逻辑集中更清晰。

### R9 · RootSwitcher 右键打开新文件夹

- [RootSwitcher.vue](src/components/RootSwitcher.vue) `.root-current` 加 `@contextmenu.prevent="onHeaderContextmenu"`:弹单菜单项"打开新文件夹";右键不展开下拉。

### R11 · 视频总时长

- [format.js](src/utils/format.js) 加 `formatDuration(sec)`:M:SS / ≥1h 用 H:MM:SS;无效(损坏/Infinity)返回空串。
- [SmartFile.js](src/models/SmartFile.js) 加 `get duration`(读 `_meta.duration`);`fileToSnapshot`/`fileFromSnapshot` 透传 `_meta.duration`(旧快照无字段时安全跳过,getter 返回 undefined)。
- [thumbnail-strategies.js](src/services/thumbnail-strategies.js) video strategy `onLoadedMetadata` 顺带写 `_meta.duration`(仅首次 + `Number.isFinite` 有效值)。
- [thumbnail.js](src/services/thumbnail.js) 视频非缓存生成路径检测到 duration 首次写入 → 调 `afterTreeMutation(currentRootId)`。
- [PhotoCard.vue](src/components/PhotoCard.vue) 视频卡片左下角时长 badge。

**关键设计点(持久化)**:`_meta.duration` 写入不自动置 `rootDirty`,若不处理则刷新后丢失。在 `thumbnail.js` 非缓存视频生成路径、检测到 duration **首次写入**(`file.duration !== beforeDuration`)时调 `afterTreeMutation` 置脏 + 调度持久化。

**边界**:`getThumbnailFromDB` 命中(缓存)时不再走 strategy,不会抽 duration。即 R11 之前已缓存的视频,时长会一直为空,需清缓存或重扫才补。属可接受边界。

## 三轮体验反馈修复(用户验收驱动)

| 反馈 | 根因 | 修法 |
|---|---|---|
| 侧栏应禁原生右键(除有自定义菜单处) | 各节点 preventDefault,空白处仍弹原生 | `#sidebar` 根 `@contextmenu.prevent` 吞原生;节点自定义菜单已 `stopPropagation` 不受影响 |
| 已开右键菜单时,空白处再右键应关闭旧菜单(而非无反应) | `useOverlay.outsideClick` 只监听 `click`,右键(`contextmenu`/右键 mousedown)不触发 | `#sidebar` `onSidebarContextmenu` 里 `if (contextMenu.visible) hide()`;RootSwitcher header 右键补 `stopPropagation` 防冒泡被关 |
| 拖拽"拖第4到第3无响应,要拖两次" | 旧 before/after 半区 + 移除自身后 `indexOf(target)` 算插点 → 相邻项下半落回原位 | 落点按"非被拖项中心"算,移除自身后回插(见 R1) |
| 拖拽动画简陋,要安卓式挤位 | 旧方案只有松开时一根蓝线 | TransitionGroup live reorder + FLIP(见 R1) |
| 拖拽鼠标闪禁用光标 | dropdown 外区域 dragover 未 preventDefault;更深:`dragenter` 默认禁用光标,只 preventDefault dragover 不够 | document 级 `dragover`+`dragenter` 双 preventDefault(见 R1) |
| 爱心挡住文件大小 | 爱心常驻左上,与 hover 下滑的顶部 meta 重叠 | 爱心 hover 时 `translateY(100%)` 与 Video 角标同步下移(用户后续表示仍不满意,已悬置) |

## 风险 / 注意点

- **favorites 响应式**:`toggle` 靠整体替换 Set 触发;`isFavorite` 在 PhotoCard computed 内读 `.has`,Set replace 后重算。当前 OK,若未来高频调用需留意。
- **R1 全局 drag 监听**:`dragenter`/`dragover` 仅 `dragId` 存在期间挂载;root 拖拽期间全局允许 drop,但 root `dragstart` 不设 `application/x-photo-path`,故不与 SidebarTreeItem 的文件移动 dropzone 误触。已加 `onBeforeUnmount` 兜底清理。
- **R11 缓存边界**:见上文,R11 前已缓存的视频时长需清缓存/重扫补全。
- **R3 重挂粒度**:`triggerRedraw` 重挂当前视图全部卡片(虚拟化下几十张),单图变更时略宽,但 modal 单开场景可接受。
