## 新增（记录，不急做）

### R17. 蓝牙耳机按钮控制播放/暂停（MediaSession API）
- 用 `navigator.mediaSession` 接入耳机/锁屏/系统媒体键。
- 至少 **play / pause**；可扩 **previoustrack / nexttrack**（接 `modal.prev/next`）、**seekbackward/forward**。
- 绑定 modal 内当前视频/音频：打开时设 `metadata`（标题=文件名，artwork 可用缩略图）+ `setActionHandler` + 同步 `playbackState`（playing/paused/none）；关 modal 置 none 释放。
- 落点：MediaView / AudioPlayer（与 R5 自动播放、R12 KeepAlive 生命周期联动）。
- 纯本地、无新依赖、桌面浏览器（Chrome/Edge）支持良好。

### R18. 缩略图大批重生期滚动卡顿（重绘当前后）
- 现象：`forceRegenerateCurrentThumbnails` 清空全部缩略图后，向下滚动、视窗触发**大批**缩略图生成时，滚动有卡顿。
- 现状：R15 已把 md5 哈希挪进 worker（主线程最大头已解决）；但**缩略图生成本身**仍有主线程活——`createImageBitmap`（已离主线程）+ `drawImage`（主）+ `canvas.toBlob` jpeg 编码（主，较重）+ IDB 写。大批并发时主线程饱和 → 掉帧。
- **需先定位瓶颈**再决定优化方向，候选：
  - 滚动高峰期货节流（快滚时暂停生成、停手再补）；
  - resize+toBlob 用 OffscreenCanvas 进 worker（R15 当时列为"进阶"，未做）；
  - 降低编码成本（更低质量 / 更小 targetSize）。
- 不急；等排期。
