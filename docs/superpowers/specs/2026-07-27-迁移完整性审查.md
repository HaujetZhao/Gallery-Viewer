## 一、已修复问题

### Phase 1：7 个确定性 bug（commit `8ba9f72`）

| # | 问题 | 根因 | 修法 |
|---|---|---|---|
| 1 | 右键菜单位置不跟随 | `ContextMenu` 定位写在 `watch(visible)`，连续右键 visible 终态恒 true 不触发；模板无 `:style` 绑定 | 改监听 `[visible,x,y]` + 模板 `:style` 响应式绑定；`show()` 去多余 `hide()` |
| 2 | 触摸单指拖图触发页面滚动 | `onTouchMove` 单指分支漏 `preventDefault` | 补 `e.preventDefault()` |
| 3 | 触摸双指缩放下限用错常量 | `MIN_SCALE`(0.1) 应为 `minScale.value` | 改 `minScale.value`，与滚轮一致 |
| 4 | EXIF ISO 不显示 | exifr 输出 `ISO`，代码用 exif-js 旧名 `ISOSpeedRatings` | 改 key |
| 5 | EXIF 曝光补偿落进"其他"组 | exifr 用 `ExposureCompensation`，代码写 `ExposureBias` | 改 key |
| 6 | 刷新当前目录功能丢失 | 原版顶部刷新按钮（`handleRefreshAction`）未迁移，只剩设置里"重载项目" | Gallery 加刷新按钮，`allMedia→reloadProject` 否则 `refreshFolder` |
| 7 | 拖图片到外部下载失效 | `onDragstart` 只写 `x-photo-path`，丢失 `uri-list`/`plain`/`DownloadURL` | 补回 4 种 MIME，`effectAllowed` 改 `'all'` |

### Phase 2：死代码清理（commit `bd75660`，净删 57 行）

- **TreeNode** 删 `syncChildren`/`addChild`/`removeChild`/`children`/`active`/`setActive`/`setInactive`（响应式下无用，外部仅用 `expanded`/`isEmpty`/`toggleExpanded`/`refreshState`/`destroy`）。96→46 行。
- **modal.css** 删 `.dragging-mode` 死规则（Ctrl 拖拽穿透未迁移，无 JS 添加该 class）。

### Phase 3：约定1 去 `.js` 扩展名（commit `ea39eee`，31 文件 91 处）

迁移期为 node 原生 ESM 验证统一带 `.js`，重构完成后改用 Vite 自动解析，省略扩展名（符合 IDE/Vite 惯例）。

### Phase 4：中严重度批（commit `e0232c7`）

- **搜索 debounce**：`useGallerySearch` 拆 `searchTerm`（即时）/`debouncedTerm`（300ms），Gallery 用后者过滤，大画廊不再每键全量重排。
- **formatFileSize**：对齐 `formatBytes`，`parseFloat` 去尾零（`100.00 B` → `100 B`）。
- **refreshFolder 失效**：`folder===currentFolder` 时切到 `parent`/`allMediaFolder`，避免 Gallery 停在幽灵文件夹。
- **handleDeleteFolder**：递归清后代 `foldersData` 缓存（`path + '/'` 前缀）；`currentFolder===allMediaFolder` 时 `switchToAllPhotos` 重聚合（原 ALL_MEDIA 视图删文件夹会残留已删子树文件）。
- **Gallery 空状态**：`displayFiles` 空时显示 `.empty-state`（区分搜索无结果 / 文件夹空）。
