## R15 · md5 哈希迁 Web Worker

**新增文件**:[src/utils/md5.worker.js](../../src/utils/md5.worker.js)。
**改文件**:[src/utils/file.js](../../src/utils/file.js)。

- worker:`globalThis.onmessage` 收 `{id, buffer}` → `SparkMD5.ArrayBuffer.hash` → 回 `{id, hash}`(用 `globalThis` 替 `self`,过 no-restricted-globals)。
- 主线程 `calculateMD5(file)` 改异步走 worker:单 worker + `pending: Map<id,{resolve,reject}>` 队列;主线程读出前 2MB ArrayBuffer 后 **transfer**(`postMessage({id,buffer},[buffer])`)零拷贝进 worker。`chunkSize=2097152` 锁定不变(旧 IDB key 兼容)。
- **in-flight 去重**:`WeakMap<file, Promise>` 命中复用同一 Promise(防快速滚动对同一文件重复算),算完删除。
- **生命周期 + 兜底**:worker 单例常驻;构造失败 / `onerror` 崩溃 → reject 全部 pending + 置 `workerBroken=true` → 后续 `hashInWorker` 回退主线程同步算。`calculateMD5` 对外签名仍是 `Promise<string>`,thumbnail.js 无需改。
- **测试环境守卫**:`workerBroken = import.meta.env?.MODE === 'test'` 初始化 → jsdom(Vitest 环境)无法加载模块 worker,直接走主线程,避免 `file.test.js` 的 `calculateMD5` 用例挂起。dev/prod 不受影响。

**验收点**:滚动顺滑(主观);同文件 hash 与改前一致(已有等价性单测覆盖);并发不重复算(WeakMap 去重)。

## R12 · modal DOM 缓存(KeepAlive,LRU 10)

**新增文件**:[src/components/MediaView.vue](../../src/components/MediaView.vue)。
**改文件**:[src/components/MediaModal.vue](../../src/components/MediaModal.vue)、[src/composables/useModal.js](../../src/composables/useModal.js)。

- **抽 `MediaView` 子组件**:image/video/svg/audio 渲染(含 R3 `detectFileChange`、ensureBlobUrl、SVG `loadSvg`、loader、R5 自动播放/时长回填)全部从 MediaModal 搬进 MediaView,props 接 `file`,按 mediaKind 渲染对应元素。
- **`<KeepAlive :max="10">`**:MediaModal 内 `<KeepAlive :max="10"><MediaView :key="mediaKey" :file="currentFile" /></KeepAlive>`,`mediaKey = file.path || '__empty__'`(会话内稳定;rename 后 miss 可接受)。LRU 10 超出自动卸载最旧;视频 currentTime 由组件实例存活隐式保留(无需专门存进度)。
- **modal 容器 `v-if` → `v-show`**(保留 Teleport):让 KeepAlive 缓存跨「关掉再打开」存活(原版 close() 不清缓存的等价语义)。关闭时 `currentFile=null` → 激活 `__empty__` 实例,真正看过的图留在缓存。
- **useModal 协调**:手势(挂 modalEl)+ 变换(scale/pointX)+ 键盘仍留 useModal;渲染态(svgText/loading/fitted/imgSrc)下移到 MediaView(每个缓存实例独立,避免共享态互相覆盖)。MediaModal `provide('modalMedia', { setMediaEl, resetTransform, initializeMediaDisplay, setIsHoveringVideo })`;MediaView `inject` 后在 `onMounted`/`onActivated` 注册当前媒体元素 + 重置变换(图片已 loaded 顺带 fit),`onDeactivated` 暂停视音频 + 检出内容变则 triggerRedraw。
- 状态隔离关键点:KeepAlive 缓存的非激活实例不在 render tree,props 冻结,不会随 `currentFile` 变动被 patch;只有当前 key 对应的实例被渲染/patch,故 `:file="currentFile"` 永远匹配当前激活实例。
- **资源池兼容**:缓存的 blobUrl 依赖 fileResource 池——`peek` 读 url,池对存活 file 不回收(本就如此);MediaView `onDeactivated` 不 dispose,缓存存活期间 hold 引用。

**验收点**:切走再切回同图瞬开(无 load 闪烁);关掉再打开同图仍瞬开;视频回看进度在;缓存超 10 淘汰最旧。

## R5 · 视频自动播放 + 时长回填(不存进度)

**前置 R12 已完成**(媒体渲染在 MediaView 内)。
**改文件**:[src/components/MediaView.vue](../../src/components/MediaView.vue)。

- `<video @loadedmetadata>`:
  - 调 `detectFileChange(file)`(R3 已有,比 _meta 变则清 md5)。
  - **时长回填**:`file.duration == null && Number.isFinite(video.duration)` → 写 `file._meta.duration` + `afterTreeMutation(currentRootId)` 置脏持久化(同 R11 套路,解决 R11 老缓存视频时长为空的边界)。
  - **自动播放**:`video.play()`;reject `NotAllowedError`(浏览器拦带声)→ `video.muted=true` 再 `play()`(静音续播);其它 reject(AbortError 切换中断等)`.catch(()=>{})` 静默忽略。
- **切换走时暂停**:`onDeactivated` 钩子 `video.pause()`;`onActivated` 时(缓存视频重新激活,readyState≥1)重新 `tryAutoplay`(从缓存的 currentTime 续播)。
- 图片/svg/音频不受影响。

**验收点**:打开视频自动播;被拦则静音播;左右切到视频也自动播;切走停止、切回复播;loadedmetadata 后 `video.paused===false`。
