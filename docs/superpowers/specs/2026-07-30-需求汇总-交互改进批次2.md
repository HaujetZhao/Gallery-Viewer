## ① 细节明确（可直接设计）

### R1. 根切换列表 · 拖拽手动排序
- 整行 `draggable`（原生 HTML5 拖拽，复刻 [PhotoCard.vue:64](../../src/components/PhotoCard.vue#L64) 图片那套），靠"指针移动"区分点击/拖拽，**不长按**。
- 点击行 = 切换根；按住移动 = 排序。底部"打开新文件夹"固定、不参与拖拽。
- 顺序写回 `rootStore.roots`（splice）+ 持久化 IDB，切根/重启顺序不变，**无需新增字段**。
- 落点：[RootSwitcher.vue](../../src/components/RootSwitcher.vue) 的 `.root-item`。

### R2. 切根后深层扫描（名字集合校验，递归整树）
- 现状：切到已有根（有快照）只 `rootEagerScan` 扫**根一层**（[folderActions.js:54-61](../../src/services/folderActions.js#L54-L61)），深层点开才校验。
- 改：秒显快照后，后台**递归遍历整棵树**做名字集合校验（`sameNameSet` 短路零 IO），变了的对**新增文件** enrich（读 size/mtime）。
- **不做内容"改"检测、不上 `detectMetaChanges`**。成本可控（典型库 ~100 文件夹的 `values()` 列表）。

### R3. "改"检测挪到 modal 打开时
- 打开媒体（MediaModal 本就读内容）顺手 `getFile` 读 size/mtime 比对 `_meta`，变了 → 清 md5 → 视窗/缩略图机制（useThumbnail）自动重算 md5 + 刷新缩略图。
- 落点：[MediaModal.vue](../../src/components/MediaModal.vue)。

### R4. 根目录右键菜单
- 现状：[SidebarTreeItem.vue:32-40](../../src/components/SidebarTreeItem.vue#L32-L40) 对 `isRoot` 直接 `return` → 弹浏览器**原生**右键菜单。
- 改：根目录也 `e.preventDefault()` + 弹**与子目录相同的菜单**，但"删除文件夹"项**禁用灰显**。contextMenu 菜单项需加 `disabled` 字段支持。

### R5. 视频自动播放 + 断点续播（含左右切换）
- 凡当前媒体是视频（首次打开 **或** `prev/next` 切到视频）→ 自动播放 + 从断点续播。
- 切换时先存上一视频进度，再载入新视频恢复其进度。
- 落点：[MediaModal.vue:53-62](../../src/components/MediaModal.vue#L53-L62) `<video>`；监听 `currentFile`/`mediaKind` 一套覆盖开/切。
- 进度按 **md5** 为 key 存 IDB（内容寻址，改名/移动后续播不丢）。

### R6. 收藏（md5 标签）+ 卡片爱心
- md5 为 key 的收藏集合（IDB 轻量 Set），内容寻址、跨改名/移动/副本共享。
- 卡片左上角爱心（[PhotoCard.vue](../../src/components/PhotoCard.vue)）：
  - **已收藏**：实心爱心，**常显**。
  - **未收藏 + hover**：空心爱心，点击 → 收藏（变实心、随后常显）。
  - 未收藏 + 未 hover：不显示。
- 切换方式：鼠标点爱心 + 快捷键 `L`（modal 内切当前媒体；hover 卡片时切那张）。
- 渲染中的卡片必有 md5（虚拟化 + 视窗触发），无时序问题。

### R7. modal 上/下键切图
- 现状：[useModal.js:226-269](../../src/composables/useModal.js#L226-L269) hover 视频时左右键被进度条抢走。
- 改：新增 `ArrowUp`/`ArrowDown` = 上一张/下一张，**无条件生效**（上下键不被视频段拦截）；左右键保留。加 `preventDefault` 防页面滚动。

### R8. 会话内稳定排序
- 现状：[Gallery.vue:23-37](../../src/components/Gallery.vue#L23-L37) `displayFiles` 是 computed，name/size/mtime 一变就重排 → rename 后文件"飞走"。
- 改：会话内顺序**冻结**在"载入/刷新那一刻"；rename/delete/move/enrich 都不重排；只有刷新页面 / 切走再切回 / 点侧栏文件夹 / 用户主动改排序方式时才重排。
- rename 后文件留原位、只换标签。

### R9. RootSwitcher 右键打开新文件夹
- 给 header 按钮（`.root-current`）加 `@contextmenu.prevent`，弹右键菜单含"打开新文件夹"，免去下拉滚到底。
- 附带确认：下拉 `max-height:60vh` **已存在**（[RootSwitcher.vue:142-143](../../src/components/RootSwitcher.vue#L142-L143)），是否调小待定。

### R10. 三态展开（收起 / 展开单层 / 递归展开）
- 现状：图标点击 `toggleExpanded()` 两态翻转（[SidebarTreeItem.vue:94-97](../../src/components/SidebarTreeItem.vue#L94-L97)）。
- 改：图标点击三态循环：收起 → 展开单层 → 递归展开 → 收起。沿子树写 `expanded` 布尔实现；三态用不同图标区分。

### R11. 视频总时长（卡片显示）
- 视频进入视窗、生成缩略图 + 算 md5 的同一个 pass 里，额外抽 duration（临时 `<video>` + `loadedmetadata`），存 `SmartFile._meta.duration`（随快照持久化），卡片角标处显示（如 `1:23`）。损坏视频取不到则不显示。

## ③ 待确认是否纳入

### R15. md5 计算迁 Web Worker（治滚动卡顿）
- 定位：[file.js:6-10](../../src/utils/file.js#L6-L10) `SparkMD5.ArrayBuffer.hash` **同步跑主线程**，快速滚动时多卡进视窗 → 主线程占满 → 掉帧。缩略图解码（`createImageBitmap`）已离主线程。
- 方案：把 md5 哈希搬进 Web Worker（Vite 原生支持）；进阶可把 resize+`toBlob` 编码也用 OffscreenCanvas 进 worker。
- **待用户确认**：是否正式纳入本批；以及搬移范围、worker 形态（单 worker+队列 / 小池）、传参（File vs transfer ArrayBuffer）、与池的去重联动。
