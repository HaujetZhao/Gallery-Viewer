# T02 · 修撤销栈两个真 bug

> **For agentic workers:** REQUIRED SUB-SKILL: 用 `superpowers:executing-plans` 或 `subagent-driven-development` 按步执行。步骤用 `- [ ]` 跟踪。

> **本文件自包含**——执行者无需其他对话上下文。

**Goal:** 修复撤销栈两个会导致**数据安全问题**的真 bug:① 跨根撤销动错磁盘;② undo 失败永久丢栈 + 落盘「撤销了一半」的状态。

**Architecture:**
- Bug 1 收口到 `resetFoldersData`(所有切根/重载必经的「重置运行时树」入口),开头清撤销栈——单一位置防漏。
- Bug 2 改 peek→undo→pop(成功才 pop,失败 op 留栈顶可重试),`schedulePersist` 移到 pop 之后(undo 抛错则不落盘)。
- 带单元测试(纯 Pinia + mock,**不碰真磁盘**)。

**Tech Stack:** Vue 3 + Pinia + Vitest

---

## 背景:两个 bug 的证据(架构师已核实)

**Bug 1(跨根撤销动错磁盘):** `history.clear()` 定义并 export([history.js:36](../../../src/stores/history.js#L36))但**全项目零调用**;`switchToRoot` / `openFolderPicker` / `reloadProject` 切根时不清栈。根A 删文件 → 切根B → Ctrl+Z → `FileDeleteOperation.undo()` 用 `useFsStore().rootHandle`([operations.js:106](../../../src/services/operations.js#L106),此刻已是根B)去根B 找 `.trash` → 越界(根B 没有那个 .trash 源 → 抛错,但栈已乱)。

**Bug 2(undo 失败丢栈 + 落盘半状态):** `undoLastOperation`([history.js:29](../../../src/stores/history.js#L29))`const op = stack.value.pop()` 在 `await op.undo()` **之前**。undo 抛错(目录被删 / handle 失效)→ op 永久出栈;而 [history.js:32-33](../../../src/stores/history.js#L32-L33) 的 `rootDirty + schedulePersist` 仍执行 → 把「撤销了一半」的脏状态落盘。对一个真动磁盘的系统,栈丢了 = `.trash` 里那份镜像文件再也回不来。

## 二、Bug 2:undo 失败保留栈 + 不落盘

**Files:** Modify `src/stores/history.js`

- [ ] **Step 2.1:`undoLastOperation` 改 peek→undo→pop**

把当前(约 26-35 行):
```js
async function undoLastOperation() {
  if (!stack.value.length)
    throw new Error('没有可撤销的操作');
  const op = stack.value.pop();
  await op.undo();
  const fs = useFsStore();
  fs.rootDirty = true; // undo 也改了树
  schedulePersist(useRootStore().currentRootId); // undo 同样 debounced 持久化
  return op;
}
```
改为:
```js
async function undoLastOperation() {
  if (!stack.value.length)
    throw new Error('没有可撤销的操作');
  // 先 peek 不 pop:undo 失败则 op 留栈顶可重试(T02 Bug2)。
  // 旧实现先 pop 再 await,undo 抛错 → op 永久出栈 + .trash 镜像成孤儿 + 仍落盘半撤销状态。
  const op = stack.value[stack.value.length - 1];
  await op.undo(); // 失败则抛出,下方不执行(op 留栈、不落盘)
  stack.value.pop(); // 成功才 pop
  const fs = useFsStore();
  fs.rootDirty = true; // undo 也改了树
  schedulePersist(useRootStore().currentRootId); // undo 同样 debounced 持久化
  return op;
}
```

### Test A:history store undo 行为(新建 `src/stores/history.test.js`)

- [ ] **Step 3.1:新建测试文件**

创建 `src/stores/history.test.js`:
```js
import { createPinia, setActivePinia } from 'pinia';
import { beforeEach, describe, expect, it, vi } from 'vitest';
import { useHistoryStore } from './history';

// history.js import schedulePersist from filesystem;mock 掉避免真 timer + 隔离落盘断言。
vi.mock('../services/filesystem', () => ({ schedulePersist: vi.fn() }));

describe('history undoLastOperation', () => {
  beforeEach(() => setActivePinia(createPinia()));

  it('undo 失败 → op 留栈顶 + 不落盘(T02 Bug2:失败不丢栈)', async () => {
    const history = useHistoryStore();
    const { schedulePersist } = await import('../services/filesystem');
    schedulePersist.mockClear();

    const failingOp = {
      execute: vi.fn(async () => {}),
      undo: vi.fn(async () => { throw new Error('磁盘失败'); }),
      getDescription: () => '测试操作',
    };
    await history.executeOperation(failingOp);
    expect(history.stack.length).toBe(1);

    await expect(history.undoLastOperation()).rejects.toThrow('磁盘失败');
    expect(history.stack.length).toBe(1); // op 仍在栈顶(未丢,可重试)
    expect(failingOp.undo).toHaveBeenCalledTimes(1);
    expect(schedulePersist).not.toHaveBeenCalled(); // 失败不落盘
  });

  it('undo 成功 → pop + 落盘', async () => {
    const history = useHistoryStore();
    const { schedulePersist } = await import('../services/filesystem');
    schedulePersist.mockClear();

    const okOp = {
      execute: vi.fn(async () => {}),
      undo: vi.fn(async () => {}),
      getDescription: () => '测试操作',
    };
    await history.executeOperation(okOp);
    await history.undoLastOperation();
    expect(history.stack.length).toBe(0); // 成功 pop
    expect(schedulePersist).toHaveBeenCalled(); // 成功落盘
  });

  it('空栈 → undo 抛错', async () => {
    const history = useHistoryStore();
    await expect(history.undoLastOperation()).rejects.toThrow();
  });
});
```
