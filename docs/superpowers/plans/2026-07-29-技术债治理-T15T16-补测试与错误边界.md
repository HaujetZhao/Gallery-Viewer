# Part T15:model 行为单测

## 一、SmartFile.move(T08 关键改动锚定)

- [ ] **Step T15.1:[smart-file.test.js](../../../src/models/smart-file.test.js) 加 move 测试**

复用 smart-folder.test.js 的 mock 模式(URL.createObjectURL mock)。造真实 SmartFolder + SmartFile,测 move 调 removeFile+addFile:
```js
import { SmartFile } from './SmartFile';
import { SmartFolder } from './SmartFolder';

describe('SmartFile.move', () => {
  beforeEach(() => {
    URL.createObjectURL = vi.fn(() => 'blob:fake');
    URL.revokeObjectURL = vi.fn(() => {});
  });

  it('move:源 removeFile + 目标 addFile + parent 更新', async () => {
    const source = new SmartFolder({ handle: { name: 'src', move: vi.fn(async () => {}) }, parent: null });
    const target = new SmartFolder({ handle: { name: 'tgt', move: vi.fn(async () => {}) }, parent: null });
    const file = new SmartFile({ handle: { name: 'a.jpg', move: vi.fn(async () => {}) }, parent: source });
    source.files = [file];

    await file.move(target);

    expect(source.files).not.toContain(file);  // 源移除(走 folder.removeFile)
    expect(target.files).toContain(file);       // 目标加入(走 folder.addFile)
    expect(file.parent).toBe(target);           // parent 更新
  });

  it('move:缺父级/目标 handle → 抛错', async () => {
    const file = new SmartFile({ handle: { name: 'a' }, parent: null });
    await expect(file.move({ handle: null })).rejects.toThrow();
  });
});
```
(关键:**不内联 splice**(T08 消灭的),走 `parent.removeFile` + `target.addFile`——若回退内联会断言失败。)

## 二、SmartFolder.addFile / removeFile

- [ ] **Step T15.2:[smart-folder.test.js](../../../src/models/smart-folder.test.js) 加行为测试**

```js
describe('SmartFolder 行为', () => {
  it('addFile:push + 设 parent + sort', () => {
    const folder = new SmartFolder({ handle: { name: 'f' }, parent: null });
    folder.files = [];
    const f1 = { name: 'b.jpg', parent: null };
    const f2 = { name: 'a.jpg', parent: null };
    folder.addFile(f1);
    folder.addFile(f2);
    expect(folder.files).toEqual([f2, f1]);  // sorted(a<b)
    expect(f1.parent).toBe(folder);
  });
  it('addFile:重复不加入', () => {
    const folder = new SmartFolder({ handle: { name: 'f' }, parent: null });
    folder.files = [];
    const f = { name: 'a.jpg', parent: null };
    folder.addFile(f);
    folder.addFile(f);
    expect(folder.files.length).toBe(1);
  });
  it('removeFile:splice 移除', () => {
    const folder = new SmartFolder({ handle: { name: 'f' }, parent: null });
    const f = { name: 'a.jpg' };
    folder.files = [f];
    folder.removeFile(f);
    expect(folder.files).not.toContain(f);
  });
  it('toggleExpanded:翻转', () => {
    const folder = new SmartFolder({ handle: { name: 'f' }, parent: null });
    folder.expanded = false;
    folder.toggleExpanded();
    expect(folder.expanded).toBe(true);
  });
});
```

> rename/delete 涉及 handle.move/removeEntry + 池,集成已覆盖(operations/history),T15 不补(避免测试冗余 + mock 过重)。
