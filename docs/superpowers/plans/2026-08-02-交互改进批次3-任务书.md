## 任务 R16-a · 收藏筛选 / 备注筛选（含 md5 持久化修复）

**目标**：搜索框旁两个 toggle 芯片（`❤ 收藏` / `✎ 备注`），开时只显示当前视图里被收藏 / 有备注的文件；两个可叠加（AND），与搜索词过滤也叠加。

**前置修复（md5 持久化，本任务必做）**：
- **问题**：[thumbnail.js:49-58](../../../src/services/thumbnail.js#L49-L58) 首次算出 `file.md5` 后**没触发持久化**（无 `afterTreeMutation`），md5 只在内存、不可靠落盘到快照。导致切根/重载后 md5 丢失、要重新滚进视窗才算——本筛选"用缓存 md5 命中未进视窗的收藏文件"的场景会失败。
- **修法**（同 R11 duration 套路）：thumbnail.js `file.md5 = await calculateMD5(raw)` 之后加 `afterTreeMutation(useRootStore().currentRootId)`（仅在首次从 null→有值时触发，幂等）。这样 md5 稳定随快照落盘、切根复用。

**现状/约束**：
- favorites/notes 现在是 `GalleryDB.user-data` store、**按 md5 懒加载**（视窗触发），内存里没有"全量 md5 集合"。全局筛选需要全量集合 → 需新增 `getAllUserData()` cursor 扫 user-data store（用户数据量小，可接受）。
- 过滤管线在 [useGallerySearch.js](../../src/composables/useGallerySearch.js)（现按 debouncedTerm 过滤 path）。
- Gallery 的 `displayFiles`（[Gallery.vue](../../src/components/Gallery.vue)）按 R8 冻结序号排，过滤在其之前/之中叠加即可（过滤与排序正交）。

**改法**：
1. **db.js 加 `getAllUserData()`**：cursor 全扫 `user-data` store，返回所有条目数组（每条 `{md5, favorite?, note?}`）。
2. **favorites / notes store 各加一个"全量 md5 集合"来源**（或新建一个轻量 `useFilterStore`）：筛选开启时调 `getAllUserData()` 建两个 `Set<md5>`（`favorite===true` / 有 note），缓存到本次筛选会话；筛选关闭即丢。注意：用户可能在筛选开启时新收藏/备注 → 集合需刷新（toggle 后 invalidate 或重新拉一次）。
3. **useGallerySearch 加两个筛选开关**（`filterFavorite` / `filterNote` ref），过滤逻辑叠加：`file` 通过当 `(!filterFavorite || favSet.has(file.md5)) && (!filterNote || noteSet.has(file.md5))`。md5 未算（未进视窗）的文件在收藏/备注筛选下按"不通过"处理（保守，避免假命中）。
4. **UI**：搜索框旁加两个 toggle 芯片/按钮，点切换 `filterFavorite`/`filterNote`；激活态高亮。位置在搜索框同区域（顶栏 fixed）。

**边界**：作用域 = 当前视图文件（某文件夹筛该文件夹的；ALL_MEDIA 筛全库）；筛选开启时若集合还没拉回（async），可先显示 loading 或空，拉回后刷新。

**验收**：开收藏筛选只显收藏项、开备注筛选只显有备注项、叠加为 AND、与搜索词共存；新收藏的项在筛选下即时可见（集合刷新）。客观可测过滤逻辑（造 favSet/noteSet 断言过滤结果）。

## 任务 R16-b · modal 内 喜爱/备注/重命名 + 卡片右键补喜爱/备注

## 任务 R17 · 蓝牙耳机/锁屏媒体键（MediaSession API）

**目标**：modal 播放视频/音频时，接入耳机/锁屏/系统媒体键，至少 **play/pause**，另接 **上一首/下一首**（接 `modal.prev/next`）。

**改法**：
1. **`ensureMediaSession(el, file)`** 工具（放合适位置，如 `utils/mediaSession.js` 或 MediaView 内）：
   - 设 `navigator.mediaSession.metadata` = new MediaMetadata({ title: file.name, artist: '相册浏览器', artwork: 可选缩略图 })。
   - `setActionHandler('play', () => el.play())`、`'pause', () => el.pause())`、`'previoustrack', () => modal.prev())`、`'nexttrack', () => modal.next())`。
   - 同步 `mediaSession.playbackState`：监听 el 的 `play`/`pause` 事件设 `'playing'`/`'paused'`。
2. **绑定时机**（MediaView）：视频/音频 `loadedmetadata`（或 onActivated）后调 `ensureMediaSession`；**`onDeactivated`/关 modal** 时 `setActionHandler(name, null)` 清理 + `playbackState = 'none'`（避免后台/关闭后仍被耳机控制）。
3. **与 R5/R12 协同**：R5 的自动播放 `play()` 触发 `play` 事件 → playbackState 自动同步；KeepAlive 切换走 onDeactivated 清理、onActivated 重绑。
4. **能力探测**：`if (navigator.mediaSession)` 守卫（兼容不支持的环境，静默跳过）。

**边界**：仅视频/音频（图片/svg 不绑）；seekbackward/forward 本任务不做（可选进阶）；metadata artwork 缺省省略（避免缩略图 IO）。

**验收**：连蓝牙耳机按播放/暂停能控 modal 内视频/音频；上一首/下一首切图；锁屏/系统媒体键可见标题；切走/关 modal 不再被耳机控制。主观真机验收（用户连耳机测）。

## 任务 R19 · modal 关闭交互 + 右上角三按钮

**目标**：① modal 任意位置（含内容区）右键 → 禁原生菜单 + **关闭 modal**；② modal 右上角加 3 个圆形按钮：**① 弹出内容菜单**（R16-b 定义的 喜爱/备注/重命名/属性）/ **② 属性面板**（同卡片右键"属性"，`properties.open(currentFile)`）/ **③ 关闭**。

**现状**：
- modal 现可由 Esc 或点遮罩空白关闭（[useModal.js](../../../src/composables/useModal.js) + MediaModal backdrop click）。
- R16-b 会提供 `buildMediaMenu(file)`（喜爱/备注/重命名/属性），本任务按钮 ① 复用它。

**改法**：
1. **modal 右键 = 关闭**：MediaModal 根容器（或内容层）`@contextmenu.prevent="close"`——禁原生菜单并关 modal。注意属性面板（PropertiesPanel，Teleport 覆盖在 modal 上）打开时，其内部右键不应触发关 modal（stopPropagation 或判断 properties 未开）。
2. **右上角三按钮**（MediaModal，绝对定位右上、`z-index` 高于内容）：
   - 按钮 ①（菜单，icon `fa-ellipsis-h` 或 `fa-bars`）：click → `contextMenu.show(clientX, clientY, buildMediaMenu(currentFile))`（位置取按钮下方）。
   - 按钮 ②（属性，icon `fa-info-circle`）：click → `properties.open(currentFile)`。
   - 按钮 ③（关闭，icon `fa-times`）：click → `modal.close()`。
   - 按钮 `@click.stop` 防冒泡到 backdrop（避免点按钮误触发遮罩关闭逻辑）；按钮自身右键也应 prevent + 关闭（与"任意位置右键关闭"一致）或 stopPropagation——取一致：右键任一按钮也关 modal。
3. **与现有 Esc/遮罩关闭并存**：三种关闭路径（Esc、点遮罩空白、右键任意处、关闭按钮）都走 `modal.close()`，行为统一。

**边界**：按钮不遮挡媒体内容（小圆形、半透明、hover 高亮）；属性面板打开时右键属性面板内部不关 modal；按钮 ① 弹的菜单项行为与 R16-b 一致（md5 未就绪时喜爱项禁用）。

**验收**：modal 内容/空白任意处右键都关闭且无原生菜单；右上 3 按钮各生效；按钮 ① 菜单与卡片右键同款；主观手感用户验。

**依赖**：R16-b（提供 `buildMediaMenu`）。执行顺序在 R16-b 之后。
