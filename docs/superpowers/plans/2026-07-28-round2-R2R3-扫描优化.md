# Round 2 · R2+R3:扫描优化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 打开即信(fromSnapshot)+ root 一层 eager 校验 + 深层按需 + 变更才持久化(dirty flag)+ fileCount 缓存。重复打开无变更 = 0 readdir / 0 getFile / 0 IDB 写 / 0 全树计数。

**Architecture:** 把 `scanAndPersist`(每次打开全树后台扫 + 全量持久化 + 全树计数)拆成:显示走 snapshot、校验走 `rootEagerScan`(root 一层 trust)+ 深层点开 `scanFolder(trust)`、持久化走 `persistIfDirty`(dirty 才 saveScan + getAllFiles)。dirty 由 `integrateScanResult` 检测增删 + history 文件操作置脏。

**Tech Stack:** Vue 3 / Pinia / Vitest + jsdom / 现有 scanFolder trust 短路。

**设计依据:** [2026-07-28-round2-R2R3-扫描优化-design.md](../specs/2026-07-28-round2-R2R3-扫描优化-design.md)(已认可并 commit)

export function integrateScanResult(folder, result, fs) {
  folder.files = result.files;
  folder.subFolders = result.subFolders;
  for (const sub of result.newSubFolders)
    fs.foldersData.set(sub.path, sub);
  for (const sub of result.removedFolders)
    fs.foldersData.delete(sub.path);
  for (const f of result.removedFiles)
    f.dispose();
  // R3:有增删 → 标树脏(persistIfDirty 据此决定是否持久化)
  if (
    result.newFiles.length
    || result.removedFiles.length
    || result.newSubFolders.length
    || result.removedFolders.length
  ) {
    fs.rootDirty = true;
  }
}
```

// R3:仅树脏时持久化(W2/W3:未变则零 saveScan / 零 getAllFiles)。
export async function persistIfDirty(id) {
  const fs = useFsStore();
  if (!id || !fs.rootDirty)
    return;
  const root = fs.rootFolder;
  if (!root)
    return;
  await saveScan(id, root.toSnapshot());
  await useRootStore().updateMeta(id, { fileCount: root.getAllFiles().length });
  fs.rootDirty = false;
}
```

    await op.execute();

```js
  async function undoLastOperation() {
    if (!stack.value.length)
      throw new Error('没有可撤销的操作');
    const op = stack.value.pop();
    await op.undo();
    useFsStore().rootDirty = true; // undo 也改了树
    return op;
  }
```
