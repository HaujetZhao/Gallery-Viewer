Expected: 构建成功，`dist/index.html` 自包含（JS/CSS/字体 base64 内联）。

- [ ] **Step 2: 核对单 HTML 离线可用**


**用户验收（关键）**：把 `dist/index.html` 单独拷到任意位置（如桌面），双击用浏览器打开（`file://`）→ 应能离线运行（启动页 + 打开文件夹 + 画廊 + modal + 文件管理全部功能，无外部请求）。这是「单 HTML」核心承诺。

- [ ] **Step 3: PWA build**

Run:
```bash
cd "d:/repos/相册浏览器-pwa" && rm -rf dist && npm run build:pwa 2>&1 | tail -8
```
Expected: 构建成功，`dist/` 含 index.html + manifest.webmanifest + sw.js + registerSW.js + icon-192/512.png + assets/ + workbox-*.js。

- [ ] **Step 4: 核对 PWA 产物**

Run:
```bash
cd "d:/repos/相册浏览器-pwa" && ls dist/ && cat dist/manifest.webmanifest && grep -oE "fa-[a-z]+-[0-9]+-[A-Za-z0-9_]+\.woff2" dist/sw.js | head -3
```
Expected: dist 含 manifest/sw/registerSW/icon/assets/workbox；manifest 字段（name 相册浏览器/theme_color #2d3e50/icons）；sw.js 预缓存含 fa-*.woff2 字体。

**用户验收（关键）**：`npm run preview` 或本地静态服务器跑 `dist/`（PWA 需 http/https，不能 file://）→ Chrome 安装（地址栏装应用图标）→ 离线打开仍可用（SW 预缓存）。

- [ ] **Step 5: 清理 dist**

Run:
```bash

```
