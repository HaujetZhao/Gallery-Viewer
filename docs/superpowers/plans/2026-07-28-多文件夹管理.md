# 多文件夹管理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or executing-plans。本计划由主会话 inline 执行。

**Goal:** 支持打开过的多个根文件夹记录、Sidebar 切换器秒切换、打开新文件夹,单根运行时模型不变。

**Architecture:** model 加 rehydrate(toSnapshot/fromSnapshot) + blobUrl 懒建;持久化三层(handleStore 多根 / scanCache / rootStore 响应式镜像);filesystem 加 switchToRoot(秒显缓存+后台校验);RootSwitcher 组件 + 启动页列表。

**Tech Stack:** Vue3 + Pinia + idb-keyval + Vitest。设计文档:`docs/superpowers/specs/2026-07-28-多文件夹管理-design.md`。

## Task 1: SmartFile rehydrate + blobUrl 懒建

**Files:** Modify `src/models/SmartFile.js`; Test `src/models/smart-file.test.js`

**关键改动**:
- 构造加 `_size`/`_lastModified` 缓存(从 file 复制);`size`/`lastModified` getter fallback `this.file?.size ?? this._size`。
- `blobUrl` 改懒:构造仍建(正常 scan 路径有 file);加 `async ensureBlobUrl()`(null 时 `file = await handle.getFile(); blobUrl = URL.createObjectURL(file)`)。
- `toSnapshot()` → `{ handle, name, size, lastModified, md5 }`(name 用 handle.name,size/lastModified 用 getter)。
- `static fromSnapshot(snap, parent)` → 用 `Object.create` 建实例,`file=null`、`blobUrl=null`、`_size/_lastModified/md5` 从快照、parent 接回。**sync**(零 IO)。

**测试**(mock handle):
```js
const mockHandle = { name: 'a.jpg', getFile: async () => ({ name: 'a.jpg', size: 100, lastModified: 200 }) };
const f = new SmartFile({ handle: mockHandle, file: { name: 'a.jpg', size: 100, lastModified: 200 }, parent: null });
f.md5 = 'abc';
const snap = f.toSnapshot();
expect(snap).toMatchObject({ handle: mockHandle, name: 'a.jpg', size: 100, lastModified: 200, md5: 'abc' });
const f2 = SmartFile.fromSnapshot(snap, null);
expect(f2.size).toBe(100);
expect(f2.name).toBe('a.jpg');
expect(f2.blobUrl).toBeNull();
expect(await f2.ensureBlobUrl()).toBeTruthy(); // 触发 getFile
```

## Task 6: filesystem switchToRoot + openFolderPicker + getAllFiles

**Files:** Modify `src/services/filesystem.js`

**新增**:
```js
export async function switchToRoot(id) {
  const handle = await handleStore.getHandle(id);
  if (!handle) { rootStore.remove(id); toast.error('文件夹记录已失效'); return; }
  if (!(await handleStore.verifyPermission(handle))) { toast.error('未获得权限'); return; }
  const fs = useFsStore();
  try {
    const snap = await loadScan(id);
    if (snap) {
      // 秒显:从快照重建
      fs.foldersData.clear();
      const root = SmartFolder.fromSnapshot(snap, null);
      fs.rootHandle = handle;
      fs.foldersData.set('ALL_MEDIA', fs.allMediaFolder);
      fs.foldersData.set(root.path, root);
      fs.rootFolder = root;
      fs.currentFolder = root;
    } else {
      await initProject(handle); // 无缓存,正常扫
    }
  } catch (e) {
    console.warn('快照恢复失败,回退重扫:', e);
    await initProject(handle);
  }
  rootStore.setCurrent(id);
  rootStore.updateMeta(id, { lastUsed: Date.now() });
  startBackgroundScan(fs.rootFolder); // 后台校验
  // 校验后存快照 + 更新 fileCount(在 startBackgroundScan 的 .then 里,见下)
}
```
- `startBackgroundScan` 调用方改为 `.then` 后 `saveScan(currentRootId, root.toSnapshot()) + updateMeta(fileCount)`。或 switchToRoot/openFolderPicker 末尾存。
- `openFolderPicker`:选新 → `initProject` → `id = handleStore.add(handle)` → `saveScan(id, root.toSnapshot())` → `rootStore.add(id, name, fileCount, now) + setCurrent(id)`。
- `getAllFiles(folder)`(已有,用于 fileCount):`root.getAllFiles().length`。

**启动恢复**(App.vue,Task 9 改):`handleStore.getLastUsed()` → 权限 granted → `switchToRoot(id)`;否则启动页"打开上次"按钮 → `switchToRoot(id)`。

**注**:`foldersData.set(root.path, root)` —— scan 时子目录已注册 foldersData,但 fromSnapshot 重建的树需重新注册所有节点 path→folder。在 `fromSnapshot` 递归里向 appState.foldersData 注册(SmartFolder.appState 可用)。或 switchToRoot 遍历树注册。**实现时在 SmartFolder.fromSnapshot 内注册 appState.foldersData**(每节点)。
