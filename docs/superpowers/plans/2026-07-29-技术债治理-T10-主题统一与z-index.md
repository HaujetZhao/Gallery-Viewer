**Goal:**
- **主题统一**:删 3 处 `@media (prefers-color-scheme: dark)` 硬编码块,改用 `[data-theme="dark"]`——让暗色由 **theme store 单一驱动**(不再「系统暗色强制」),消除双轨冲突(用户可直见的画面分裂)。
- **z-index 修复**:修两个同级冲突(modal=toast、contextMenu=confirm)+ 让 [variables.css](../../../src/styles/variables.css) 的 `--z-*` 令牌**真正被引用**(审查:定义了 80+ 令牌却不用)。

**Why:** 审查根因 3——CSS 双轨(theme store 注入 vs prefers-color-scheme 硬编码)+ z-index 失控(令牌不用、同级冲突:modal 开时 toast 被遮罩盖住看不见)。

**Tech Stack:** CSS(+ Tailwind v4 的 CSS 嵌套由 lightningcss 支持)

## 二、z-index:variables.css 令牌调整 + 4 浮层引用 + 修冲突

### 现状(审查核实)
- modal([modal.css:9](../../../src/styles/modal.css#L9))= 1000;toast([components.css:438](../../../src/styles/components.css#L438))= 1000 → **同级**:modal 开时 toast 被遮罩盖住看不见。
- context-menu([context-menu.css:9](../../../src/styles/context-menu.css#L9))= 10000;confirm-dialog([confirm-dialog.css:13](../../../src/styles/confirm-dialog.css#L13))= 10000 → **同级**:靠 DOM 顺序赌博。

- [x] **Step 2.1:[variables.css](../../../src/styles/variables.css) 的 `--z-*` 调到实际量级 + 加 `--z-confirm`**

把 Z-Index 层级系统段(L201-221)的值改为匹配实际浮层量级(低→高:内容 < 侧栏 < 模态 < toast < 右键菜单 < 确认框):
```css
/* ==================== Z-Index 层级系统 ==================== */
--z-base: 0;            /* 基础层 */
--z-content: 10;        /* gallery 内部(卡片/badge/悬浮条 z-2/3/10)*/
--z-sidebar: 900;       /* 侧栏 */
--z-dropdown: 100;      /* 下拉(RootSwitcher)*/
--z-sticky: 200;        /* settings-modal 等粘性 */
--z-modal: 1000;        /* 模态框(MediaModal)*/
--z-toast: 1100;        /* toast(> modal:modal 开时 toast 可见)*/
--z-popover: 2000;      /* 右键菜单(context-menu)*/
--z-confirm: 3000;      /* 确认框(confirm-dialog,最高)*/
```
(删旧的 `--z-fixed`/`--z-modal-backdrop`/`--z-tooltip`(零引用),合并成上面这套。)

- [x] **Step 2.2:4 浮层引令牌**

| 文件 | 硬编码 | 改为 |
|---|---|---|
| [modal.css:9](../../../src/styles/modal.css#L9) | `z-index: 1000` | `z-index: var(--z-modal)` |
| [components.css:438](../../../src/styles/components.css#L438) | `z-index: 1000` | `z-index: var(--z-toast)` |
| [context-menu.css:9](../../../src/styles/context-menu.css#L9) | `z-index: 10000` | `z-index: var(--z-popover)` |
| [confirm-dialog.css:13](../../../src/styles/confirm-dialog.css#L13) | `z-index: 10000` | `z-index: var(--z-confirm)` |

> 改后冲突自动消:toast(1100)>modal(1000);confirm(3000)>contextMenu(2000)。其他 z(gallery/sidebar 内部/settings-btn 等)暂不动(T14 全 CSS 重构时统一)。
