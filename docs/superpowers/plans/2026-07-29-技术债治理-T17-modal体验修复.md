## 问题 1:大图 modal 只能放大不能缩小

**根因:** [useModal.js:74](../../../src/composables/useModal.js#L74) `initializeMediaDisplay` 把 `minScale.value = initial`(= 适应屏幕的 scale);而 [onWheel:91](../../../src/composables/useModal.js#L91) `if (newScale < minScale.value) return`——缩到「适应屏幕」就触底,不能再小。

**修复(允许缩到更小):**

- [ ] **Step 1.1:`initializeMediaDisplay` 不把 minScale 锁到 initial**

[useModal.js:74](../../../src/composables/useModal.js#L74) 删除这行:
```js
minScale.value = initial;  // ← 删除(minScale 保持 ref 初始的 MIN_SCALE=0.1,允许缩到更小)
```
(`minScale` ref 初始值已是 `MIN_SCALE`(L29),不覆盖即允许缩到 0.1。)

- [ ] **Step 1.2:主观验收**
打开一张大图 → 滚轮下滚 → 应能缩到比「适应屏幕」更小(露黑边),而非卡在适应。若 0.1 太小(几乎看不见),反馈架构师调 MIN_SCALE 或改成 `initial` 的某比例。

## 问题 2:鼠标在侧栏仍触发感知滚动

**根因:** [useScrollZone.js:16-26](../../../src/composables/useScrollZone.js#L16) `isInExcluded` 只用 `getBoundingClientRect`。App.vue 的 `sidebarEl` 绑在包裹 `<div ref="sidebarEl"><Sidebar /></div>`——若 Sidebar 内部 `position:fixed`,包裹 div 的 rect 塌缩为 0,rect 检查永远落空 → 侧栏不被排除。

**修复(加 DOM 层级检查,不受 fixed 定位影响):**

- [ ] **Step 2.1:`isInExcluded` 加 `contains` 检查**

[useScrollZone.js](../../../src/composables/useScrollZone.js) 改 `isInExcluded` 签名加 target,加 contains:
```js
function isInExcluded(x, y, target) {
  for (const r of excludeRefs) {
    const el = r?.value;
    if (!el)
      continue;
    if (target && el.contains(target))
      return true; // DOM 层级(鼠标在排除元素或其后代内)——不受 fixed 定位/rect 塌缩影响
    const rect = el.getBoundingClientRect();
    if (x >= rect.left && x <= rect.right && y >= rect.top && y <= rect.bottom)
      return true;
  }
  return false;
}
```
`onMouseMove` 调用处(L33)改为:
```js
if (isInExcluded(e.clientX, e.clientY, e.target)) {
  stop();
  return;
}
```

- [ ] **Step 2.2:主观验收**
鼠标在侧栏(尤其侧栏顶部/底部 150px 边缘带)移动 → 不应触发页面滚动。移出侧栏到主区顶/底 → 应触发。

## 问题 3:点图开 modal 后,感知滚动一直保持

**根因:** [useScrollZone.js:31-32](../../../src/composables/useScrollZone.js#L31) `if (useModalStore().isOpen) return` **只 return 不 stop**,且 raf `loop`(L60-68)不检查 isOpen——所以 modal 打开前已在跑的滚动循环继续(modal 盖住看不见,但 scrollBy 还在)。

**修复(modal open 立即 stop):**

- [ ] **Step 3.1:watch modal isOpen,open→stop**

[useScrollZone.js](../../../src/composables/useScrollZone.js) import 加 `watch`:
```js
import { onBeforeUnmount, onMounted, watch } from 'vue';
```
在 `useScrollZone` 内(onMounted 前)加:
```js
// modal 打开立即停止在途的边缘滚动(T17:旧实现只 return 不 stop,raf 循环继续)
watch(() => useModalStore().isOpen, (open) => {
  if (open)
    stop();
});
```

- [ ] **Step 3.2:主观验收**
先在主区顶/底边缘触发感知滚动(页面在滚)→ 点图打开 modal → 滚动应**立刻停**(不再滚)。

## 问题 4:大图打开/切换时「闪一下再缩放到适合」

**根因:** [MediaModal.vue](../../../src/components/MediaModal.vue) 的 `<img>` 以 natural 像素渲染(`initializeMediaDisplay` 设 `width=naturalWidth`)、初始 `scale=1`(巨大),`@load` 后才 `initializeMediaDisplay` fit——fit 之前那帧的巨大原尺寸就是「闪一下」。

**修复(fit 完成前隐藏 img):**

- [ ] **Step 4.1:useModal 加 `fitted` 标志**

[useModal.js](../../../src/composables/useModal.js) 加 ref(与 loading/svgText 一起):
```js
const fitted = ref(false);
```
`onImgLoad` 改(L78-81):
```js
function onImgLoad() {
  loading.value = false;
  initializeMediaDisplay();
  fitted.value = true; // fit 完成,可显示(避免 fit 前的巨大原图闪现)
}
```
切换文件的 watch(L338-350)加 `fitted.value = false`:
```js
watch(
  () => modal.currentFile,
  (f) => {
    if (!f)
      return;
    loading.value = mediaKind.value !== 'audio';
    fitted.value = false; // 切换/打开新图:先隐藏,等 onImgLoad fit 完再显
    svgText.value = '';
    isHoveringVideo.value = false;
    if (mediaKind.value === 'svg')
      loadSvg();
    nextTick(() => resetTransform());
  },
);
```
isOpen watch 的 open 分支(L356-362)加 `fitted.value = false`:
```js
if (open) {
  window.addEventListener('keydown', onKeydown);
  nextTick(() => {
    resetTransform();
    attachGestures();
  });
  fitted.value = false; // 首次打开也先隐藏,等 load+fit
}
```
return 加 `fitted`。

- [ ] **Step 4.2:MediaModal img 用 fitted 控制可见性**

[MediaModal.vue](../../../src/components/MediaModal.vue) 解构加 `fitted`:
```js
const { loading, svgText, mediaKind, isHoveringVideo, onImgLoad, fitted } = useModal(...);
```
`<img>` 加 style(L43-51):
```html
<img
  v-if="mediaKind === 'image'"
  ref="mediaEl"
  class="modal-media modal-image"
  :src="imgSrc"
  :style="{ opacity: fitted ? 1 : 0 }"
  draggable="false"
  alt="Full view"
  @load="onImgLoad"
>
```
(opacity:0 时 img 仍占位参与 layout,fit 完 fitted=true 才显——避免闪。仅 image 走此路径;video/svg/audio 不受 fitted 影响。)

- [ ] **Step 4.3:主观验收**
打开一张大图 / modal 内左右切换 → 图片应**直接以 fit 后的尺寸出现**,不再有「巨大原图闪一下再缩小」。
