# 改造路线图

> 重构完成 + 迁移审查后的改进方向，按价值/成本分阶。
> 日期：2026-07-27。配合 [迁移完整性审查报告](superpowers/specs/2026-07-27-迁移完整性审查.md) 与 [后续待办](../后续待办.md)。

---

## 一、近期（高价值 / 低成本）

- **扫描性能**：`startBackgroundScan` 已改同级并发（`Promise.all`）。验证大目录树扫描速度；若仍慢，加扫描进度提示（Sidebar 各 folder 的 `scanned` 状态 / 顶部进度条）。
- **剩余中严重度**：滚动感应区可视化指示条 · 清缓存后主动重绘 · Ctrl+C 复制 toast · 搜索结果高亮。
- **大画廊虚拟滚动**：万级文件时 Gallery 全量 `v-for PhotoCard` 卡顿。改为虚拟列表（只渲染可见 ± 缓冲区），配合现有 masonry 列布局。

## 二、中期（约定现代化 + 健壮性）

- **约定2：model 静态注入 → 构造注入**：`SmartFolder.appState` 模块级全局改为构造参数注入，提升可测试性、消除隐式全局。
- **scan 取消（AbortSignal）**：`reloadProject` / 切根时 abort 进行中的 scan，避免旧 scan 覆盖新状态（当前 fire-and-forget 无取消）。
- **核心算法测试覆盖**：scan 增量 / GPS 坐标转换 / ID3 / `.trash` 回收 用 Vitest 加单测（都是纯逻辑，可脱离 FS Access API 测）。
- **句柄持久化**：File System Access handle 存 IDB + 启动 `requestPermission`，免每次重选文件夹（原版也未实现，体验提升明显）。

## 三、长期（大工程，充分规划后做）

- **约定4：全局 CSS → scoped**：全局 CSS 逐步迁入组件 scoped，全局收敛为 design tokens（`variables.css`）+ 通用工具类。最大杠杆也最大工程，按组件逐步迁移。
- **文件夹拖拽移动**：`SmartFolder.move` 当前 `throw`，实现 `handle.move` + 撤销栈集成。
- **TypeScript 化**：model/service/store 接口类型安全。建议在 CSS scoped 之后（避免同时两场大仗）。

## 四、质量基础设施（可随时启动，投入低收益持续）

- **ESLint + Prettier**：统一代码风格（import 顺序 / 格式 / 命名）。
- **Vitest**：单元测试框架 + 核心算法覆盖（见中期）。
- **CI**：lint + test + 双 build，作 PR 门禁。

---

## 优先级建议

1. **近期**优先——用户体感直接（扫描速度 / 中严重度 / 虚拟滚动）。
2. **中期**按需——健壮性与可维护性（约定2 / scan 取消 / 测试 / 句柄持久化）。
3. **质量基建**可立即启动——ESLint / Vitest 投入低、长期收益。
4. **长期**择机——CSS scoped / TS 是大工程，单独规划专项。
