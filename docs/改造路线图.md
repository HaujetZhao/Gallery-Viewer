## 一、质量基建（最先做 · 铺路 · 低风险 · 成熟方案）

- **ESLint**：`@antfu/eslint-config`（Vue/Vite 团队 Anthony Fu 的一体化配置，含 Vue + TS + 风格，社区事实标准）—— 不自己拼配置。
- **测试框架**：**Vitest** + `@vue/test-utils`（Vue/Vite 官方推荐，与现有 Vite 无缝）。
- **CI**：GitHub Actions（lint + test + 双 build）。
- **理由**：后续所有重构（model 注入 / CSS scoped）都需要测试兜底，越早搭越好；纯新增，不影响现有功能。

## 二、用户体感（成熟方案 · 收益直接）

- **句柄持久化**：**idb-keyval**（Jake Archibald，轻量 KV over IndexedDB）存 File System Access handle，启动 `requestPermission` 恢复，免每次重选文件夹。原版也未实现，体验提升大。
- **剩余中严重度**：滚动感应区指示条 · Ctrl+C 复制 toast · 清缓存后重绘 · 搜索高亮（小修，不依赖框架）。

## 三、架构与测试覆盖

- **核心算法测试**：scan 增量 / GPS 坐标转换 / ID3 / `.trash` 回收 用 Vitest 罩住（纯逻辑，脱离 FS Access API 可测）。
- **model 构造注入**：`SmartFolder.appState` 静态全局 → 构造参数注入，提升可测试性（配合上条测试）。
- **scan 取消（AbortSignal）**：reloadProject / 切根时 abort 进行中的 scan，原生 API。

## 四、长期（大工程 · 择机）

- **全局 CSS → scoped**：Vue 原生 scoped styles 按组件逐步迁（不引入 UnoCSS/Tailwind，避免风格大变）。全局收敛为 design tokens（`variables.css`）。
- **文件夹拖拽移动**：`SmartFolder.move` 实现（`handle.move` + 撤销栈）。
- **TypeScript 化**：Vue 官方 TS 支持，建议在 CSS scoped 之后。

## 降级 / 搁置

- **大画廊虚拟滚动**：原列 v1 近期项。二次思考后降级——masonry 不等高布局的虚拟化成熟方案缺（`vue-virtual-scroller` 只支持等高），当前缩略图懒加载（IntersectionObserver）已缓解千级文件。**万级文件真出现卡顿再评估**（可能需重构为等高网格）。

2. **句柄持久化**（二）—— 体感
3. **核心测试 + model 注入**（三）—— 架构
4. **中严重度小项**（二）—— 穿插
5. **长期**（四）—— 择机
